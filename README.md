# Project-UMKM-Tukang-Marinasi
Proyek ini merupakan analisis data penjualan yang bertujuan untuk memahami performa penjualan, perilaku pelanggan, efektivitas kanal penjualan, serta peluang ekspansi pasar pada UMKM Tukang Marinasi.
Analisis dilakukan menggunakan Python dan Pandas dengan pendekatan berbasis data untuk menghasilkan insight yang dapat digunakan sebagai dasar dalam pengambilan keputusan bisnis dan penyusunan strategi pengembangan pasar.
